# MTS v3.17 — 범례 및 마커 수정
기존 index.html을 교체한 뒤 강력 새로고침합니다. 기존 비밀번호를 유지합니다.
마커 없음: 그래프 점과 호버 점을 숨기고 범례의 색상 선과 처방명은 유지합니다.
선택 가능한 모양: 사각형, 마름모, 삼각형, 원, 십자(X), 더하기, 별, 둥근 사각형, 가로선, 짧은 선, 없음.
기본 범례와 좌표 범례에 같은 모양을 적용합니다. 데이터 입력의 마커 선택을 사용합니다.
엑셀에서는 둥근 사각형은 사각형으로, 가로선/짧은 선은 dash로 대응합니다.
기존 계산·엑셀 저장 로직은 마커 대응표와 버전 문자열을 제외하고 변경하지 않았습니다.
브라우저·Excel 실화면 검수 및 배포는 수행하지 않았습니다.
